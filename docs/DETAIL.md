# 任务面板

你是老板，会话是员工。任务由你在面板里手动建、手动推进、手动指派；对话里的助手只能替你起草待办（生成一张卡片，创建与否由你点）。面板不读取会话日志，也不会自己生成任务。

## 放在哪

左侧栏底部、齿轮旁边有一个看板图标（带未完成数角标）。点它：

- **主区保持真实对话**（对话 / 轨迹 / 统计那些页签照旧，功能一个不少）
- **右侧栏打开「任务」页签**，任务板就在里面，和主区并排

需要更宽就把右侧栏拉宽（右栏本身可展开）；关掉页签不影响数据。

## 怎么用

- **新建任务**：面板顶部输入标题，回车或点「添加」。
- **新建会话并指派**：编辑区「负责会话」里点「+ 新建会话」，先选**工作区**、写清**要求**，再点「发送并新建」——会话建在所选工作区里、自动指派给这个任务，并把要求作为第一条消息发出去，同时在**主区**打开它。发送前不会创建任何会话；如果发送失败，表单会保留已建好的会话，点「重试发送」不会重复建会话。
- **子任务**：鼠标移到任务行点 `+`，在该任务下插入输入框；回车建子任务，`Esc` 取消。层级不限，默认全部展开。
- **完成**：点行左侧圆圈即完成，再点改回待办；行内 `已完成/子任务总数` 显示进度。
- **编辑**：点标题展开编辑区，再点收起。字段：标题、状态（待办/进行中/受阻/已完成）、优先级（高/中/低）、截止日期、进展备注、负责会话。
- **看对话**：点任务行下面「负责会话」的任意一行，主区切到那个会话（任务板不动）；编辑区里每条会话也有「打开」。
- **指派会话**：「选择会话」展开可搜索列表，勾选任意多个共同负责；负责会话一行一条、显示完整标题（超过 3 条折成「还有 N 个」）。
- **移动任务**：行内「移动」→ 目标列表（顶层 + 按层级缩进的父任务 + 搜索），点一个即挂过去并展开整条分支；自身子树不出现在候选里（服务端也拒绝成环）。
- **删除**：行内「删除」→「确认删除」，连子任务一起删。
- **筛选**：未完成 / 全部 / 已完成 + 搜索标题与备注；命中的父级自动带出。

## 在对话里建待办

助手只有两个工具，都是低权限的：

| 工具 | 作用 |
|---|---|
| `task_board_list` | 读看板：默认只列未完成，可按标题或备注搜索，返回标题、状态、优先级、截止日期 |
| `task_board_propose` | 打开一张「新建待办」卡片，把想建的待办预填进去；**不写任何数据** |

卡片里可以改标题、优先级、截止日期和备注。点「创建」才真正写入 `tasks.json`，右侧面板随即刷新；点「取消」什么都不会发生。

「父任务」和面板里的「移动」一样是一棵可展开的树：点一下展开，第一行「顶层（无父任务）」，下面按层级缩进列出全部任务，顶部有搜索框；默认选中助手提议的那条，也可以改成别的或改回顶层。所以子任务既可以在对话里直接说，也可以建的时候在卡片里点一下挂过去。

助手不知道任务到底做完没有，所以：

- **不能改状态**：没有改状态的工具，完成/受阻只能你在面板里点。
- **不能删除**：删除只在面板的「删除」里。
- **不能替你决定建不建**：助理说「已创建」是不成立的，只能生成卡片。

想一次建多条，就一次说清楚，助手会连续调用 `task_board_propose`，每条一张卡片，逐张确认。父任务用 `task_board_list` 拿到 id 后传 `parentId`。

卡片出现在**这一轮的末尾**——助手把话说完之后，而不是混在工具调用那一行；翻回更早的轮次也还是这个位置。同一轮提了几条就依次排几张。

卡片上还会显示「负责会话 · 当前对话」：点「创建」后，这条任务自动指派给发起这次对话的会话，面板里直接能看到负责会话，不用再手动指派。

## 数据存在哪

`%DSH_HOME%\task-board\tasks.json`（默认 `C:\Users\<你>\.dsh\task-board\tasks.json`）。每次变更原子写入（临时文件 + rename），重启后还在；删掉文件等于清空。

## 契约与边界

- 任务字段：`id / title / status / priority / due / note / assignees[] / parentId / createdAt / updatedAt / doneAt`；子任务就是 `parentId` 指向父任务，所以层级不限。
- 一个任务可指派多个会话；只存会话 id，标题在渲染时从当前会话列表解析，改名会跟着变；会话被归档或不在列表时退回显示 id 片段且不可点。
- 面板是全局的：不区分工作区，所有任务在同一份看板里。
- 新建会话必须选中一个已登记的工作区：创建走会话服务的 `workspaceId`，会话因此一定绑定到工作区；不再用「最近会话的当前目录」去猜，也不会产生没有工作区、发不出消息的会话。
- 卡片与面板走同一条 `POST /plugin/task-board/tasks`，字段校验和成环检查只有一套，没有第二条写入路径。
- 所有请求要带 `x-task-board: 1` 头，别的网页无法通过图片或脚本引用读到任务标题；接口只监听本机回环地址。
- 会话的读写在主区的真实对话界面里完成，本插件不自绘聊天、不解析会话日志。
